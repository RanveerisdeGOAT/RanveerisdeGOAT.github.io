\doxysubsection{Detailed Description}
Wrapper around Vk\+Submit\+Info to simplify building queue submission payloads. 


\begin{DoxyItemize}
\item Manages internal lifetime for wait semaphores, signal semaphores, pipeline stage masks, and command buffers to prevent pointer dangling during submission. 
\end{DoxyItemize}
