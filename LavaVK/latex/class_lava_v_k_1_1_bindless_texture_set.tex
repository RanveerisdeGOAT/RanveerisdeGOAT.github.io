\doxysubsection{Detailed Description}
Manages a single large descriptor set of textures indexed by integer ID for "{}bindless"{} shader access. 

Rather than binding one descriptor set per draw call, {\ttfamily \doxylink{class_lava_v_k_1_1_bindless_texture_set}{Bindless\+Texture\+Set}} allocates one {\ttfamily Vk\+Descriptor\+Set} with a single binding containing a large array of {\ttfamily VK\+\_\+\+DESCRIPTOR\+\_\+\+TYPE\+\_\+\+COMBINED\+\_\+\+IMAGE\+\_\+\+SAMPLER} descriptors (\doxylink{class_lava_v_k_1_1_bindless_texture_set_af3d71f28dd47031b5d8c70f0a9010454}{MAX\+\_\+\+TEXTURES} entries at binding \doxylink{class_lava_v_k_1_1_bindless_texture_set_a4c952e7235713ee9ff1b64d7ef1efe43}{BINDING}). Textures are registered via \doxylink{class_lava_v_k_1_1_bindless_texture_set_a799471ef3f4d0346b9113dd840f1ce88}{add()}, which writes them into a free array slot and returns the slot\textquotesingle{}s index; that index can then be uploaded to the GPU (e.\+g. via push constants or a per-\/instance/\+material buffer) and used in the shader to index directly into the sampler array, avoiding descriptor set (re)binding for every different texture.

\begin{DoxyNote}{Note}
This relies on the physical device supporting descriptor indexing ({\ttfamily GPUFeatures::\+descriptor\+Indexing}, in particular the {\ttfamily partially\+Bound} and {\ttfamily runtime\+Descriptor\+Array} features) so that only some of the \doxylink{class_lava_v_k_1_1_bindless_texture_set_af3d71f28dd47031b5d8c70f0a9010454}{MAX\+\_\+\+TEXTURES} array slots need to be written at any given time; the corresponding device features must be enabled when the \doxylink{class_lava_v_k_1_1_device}{Device} is created. Descriptor writes performed by \doxylink{class_lava_v_k_1_1_bindless_texture_set_a799471ef3f4d0346b9113dd840f1ce88}{add()}, \doxylink{class_lava_v_k_1_1_bindless_texture_set_a26ea3349706061c8823be4517f840927}{remove()}, and \doxylink{class_lava_v_k_1_1_bindless_texture_set_a67116fd5717b4b732abf64c7e7bbf1ca}{update()} are not synchronized with in-\/flight GPU work:\+ only call them when the frame(s) that might reference the affected slot are known to have finished executing, or when the device additionally supports {\ttfamily update\+After\+Bind}. This class is neither copyable nor movable.
\end{DoxyNote}
