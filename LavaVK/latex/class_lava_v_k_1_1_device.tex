\doxysubsection{Detailed Description}
Manages the Vulkan physical device selection, logical device instantiation ({\ttfamily Vk\+Device}), and graphics queue retrieval. 

{\ttfamily \doxylink{class_lava_v_k_1_1_device}{Device}} is the central object most other Lava\+VK types are created from. Given a chosen \doxylink{class_lava_v_k_1_1_g_p_u_hardware}{GPUHardware} and a list of requested Queue\+Type values, it creates the logical {\ttfamily Vk\+Device}, retrieves a {\ttfamily \doxylink{class_lava_v_k_1_1_queue}{Queue}} for each requested queue type, and lazily creates one {\ttfamily \doxylink{class_lava_v_k_1_1_command_pool}{Command\+Pool}} per queue type as needed via \doxylink{class_lava_v_k_1_1_device_a22b0ab567bd146918dd2bdfe88fc93ab}{get\+Command\+Pool()}. It also exposes \doxylink{class_lava_v_k_1_1_device_ab7bd0f3a7aa436b39579aefa5249c41a}{submit()} convenience overloads that build a {\ttfamily \doxylink{class_lava_v_k_1_1_submit_info}{Submit\+Info}} from Lava\+VK synchronization objects and submit it on the appropriate queue, so callers do not need to construct {\ttfamily Vk\+Submit\+Info} by hand. {\ttfamily \doxylink{class_lava_v_k_1_1_device}{Device}} is move-\/only RAII:\+ the underlying {\ttfamily Vk\+Device} is created in the constructor and destroyed in the destructor.
