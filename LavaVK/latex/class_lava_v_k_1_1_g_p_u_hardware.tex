\doxysubsection{Detailed Description}
Lightweight, queryable handle to a physical Vulkan GPU ({\ttfamily Vk\+Physical\+Device}). 

{\ttfamily \doxylink{class_lava_v_k_1_1_g_p_u_hardware}{GPUHardware}} does not own or create any Vulkan resources — it simply wraps a {\ttfamily Vk\+Physical\+Device} (enumerated from an {\ttfamily \doxylink{class_lava_v_k_1_1_instance}{Instance}}) along with its cached {\ttfamily Vk\+Physical\+Device\+Properties}, and exposes convenience queries used when choosing which GPU to render on and which queue families to request from it. A {\ttfamily \doxylink{class_lava_v_k_1_1_g_p_u_hardware}{GPUHardware}} is passed to the {\ttfamily \doxylink{class_lava_v_k_1_1_device}{Device}} constructor to create the logical device.
