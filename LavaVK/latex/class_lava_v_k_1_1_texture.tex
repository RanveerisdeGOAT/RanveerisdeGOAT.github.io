\doxysubsection{Detailed Description}
Loads an image file from disk into a GPU-\/resident, shader-\/sampleable texture. 

{\ttfamily \doxylink{class_lava_v_k_1_1_texture}{Texture}} combines an \doxylink{class_lava_v_k_1_1_image}{Image} (created with {\ttfamily Image\+Usage::\+\+TRANSFER\+\_\+\+DST \texorpdfstring{$\vert$}{|} Image\+Usage::\+\+SAMPLED}) with a {\ttfamily Vk\+Sampler}. On construction it loads pixel data from {\ttfamily path} via stb\+\_\+image, uploads it to the GPU through a temporary staging buffer and a one-\/time command buffer (transitioning the image from {\ttfamily VK\+\_\+\+IMAGE\+\_\+\+LAYOUT\+\_\+\+UNDEFINED} to {\ttfamily VK\+\_\+\+IMAGE\+\_\+\+LAYOUT\+\_\+\+TRANSFER\+\_\+\+DST\+\_\+\+OPTIMAL} and finally to {\ttfamily VK\+\_\+\+IMAGE\+\_\+\+LAYOUT\+\_\+\+SHADER\+\_\+\+READ\+\_\+\+ONLY\+\_\+\+OPTIMAL}), and creates a {\ttfamily Vk\+Sampler} configured from {\ttfamily sampler\+Info}. The image is always loaded and uploaded as 4-\/channel (RGBA) {\ttfamily VK\+\_\+\+FORMAT\+\_\+\+R8\+G8\+B8\+A8\+\_\+\+SRGB} data, regardless of the source file\textquotesingle{}s original channel count.

{\ttfamily \doxylink{class_lava_v_k_1_1_texture}{Texture}} is neither copyable nor movable; it must be constructed in place (e.\+g. via {\ttfamily std::\+unique\+\_\+ptr\texorpdfstring{$<$}{<}\doxylink{class_lava_v_k_1_1_texture}{Texture}\texorpdfstring{$>$}{>}} or emplaced directly) and its lifetime must not outlive the owning \doxylink{class_lava_v_k_1_1_device}{Device}.

\begin{DoxyNote}{Note}
The upload path submits and waits on a temporary, transient command pool synchronously, so construction blocks until the GPU finishes uploading the texture.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
The sampler\textquotesingle{}s border color is currently always created as {\ttfamily VK\+\_\+\+BORDER\+\_\+\+COLOR\+\_\+\+INT\+\_\+\+OPAQUE\+\_\+\+BLACK}, regardless of any \+\#\+Border\+Color value; there is currently no way to customize it through \doxylink{struct_lava_v_k_1_1_texture_sampler_create_info}{Texture\+Sampler\+Create\+Info}.
\end{DoxyWarning}
