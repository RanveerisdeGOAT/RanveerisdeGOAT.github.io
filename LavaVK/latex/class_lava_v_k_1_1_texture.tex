\doxysubsection{Detailed Description}
Represents a GPU texture:\+ an \doxylink{class_lava_v_k_1_1_image}{Image} paired with a {\ttfamily Vk\+Sampler}. 

{\ttfamily \doxylink{class_lava_v_k_1_1_texture}{Texture}} combines the two resources most shader sampling operations need together:\+ an \doxylink{class_lava_v_k_1_1_image}{Image} (with its view) and a {\ttfamily Vk\+Sampler} describing how that image is filtered and addressed. It supports two creation paths:\+ allocating an empty GPU-\/only image (e.\+g. a storage image or render target) from a \doxylink{struct_lava_v_k_1_1_texture_create_info}{Texture\+Create\+Info}, or loading image data from disk and uploading it to a new sampled image. {\ttfamily \doxylink{class_lava_v_k_1_1_texture}{Texture}} is move-\/only RAII:\+ the sampler is created in the constructor and destroyed, along with the owned \doxylink{class_lava_v_k_1_1_image}{Image}, in the destructor.
