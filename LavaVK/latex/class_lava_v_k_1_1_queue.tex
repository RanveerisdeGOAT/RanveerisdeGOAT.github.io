\doxysubsection{Detailed Description}
Wrapper class managing execution operations on a Vulkan device queue ({\ttfamily Vk\+Queue}). 

{\ttfamily \doxylink{class_lava_v_k_1_1_queue}{Queue}} is a lightweight, non-\/owning handle:\+ the underlying {\ttfamily Vk\+Queue} is owned by the Vulkan implementation (retrieved via {\ttfamily vk\+Get\+Device\+Queue}) and is implicitly destroyed when the parent {\ttfamily \doxylink{class_lava_v_k_1_1_device}{Device}} is destroyed, so {\ttfamily \doxylink{class_lava_v_k_1_1_queue}{Queue}} itself has no destructor to manage and is freely copyable. Lava\+VK\textquotesingle{}s {\ttfamily \doxylink{class_lava_v_k_1_1_device}{Device}} exposes one {\ttfamily \doxylink{class_lava_v_k_1_1_queue}{Queue}} per requested {\ttfamily Queue\+Type} (e.\+g. {\ttfamily GRAPHICS}, {\ttfamily TRANSFER}, {\ttfamily PRESENT}); a {\ttfamily \doxylink{class_lava_v_k_1_1_queue}{Queue}} is used to submit recorded command buffers for execution and to present swapchain images.
