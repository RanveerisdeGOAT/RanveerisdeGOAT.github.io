\doxysubsection{Detailed Description}
Wrapper around Vk\+Command\+Buffer for recording GPU rendering and compute instructions. 

Command buffers are allocated from a \doxylink{class_lava_v_k_1_1_command_pool}{Command\+Pool} and submitted to a GPU queue for execution. Members are marked const as recording commands modifies the GPU recording state pointed to by the handle, rather than the C++ handle itself.
