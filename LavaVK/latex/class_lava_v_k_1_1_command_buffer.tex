\doxysubsection{Detailed Description}
Wrapper around Vk\+Command\+Buffer for recording GPU rendering and compute instructions. 

Command buffers are allocated from a \doxylink{class_lava_v_k_1_1_command_pool}{Command\+Pool} and submitted to a GPU queue for execution. Members are marked const as recording commands modifies the GPU recording state pointed to by the handle, rather than the C++ handle itself. {\ttfamily \doxylink{class_lava_v_k_1_1_command_buffer}{Command\+Buffer}} is a non-\/owning handle:\+ it is allocated and freed by its owning \doxylink{class_lava_v_k_1_1_command_pool}{Command\+Pool}, so it has no destructor of its own to manage and is freely copyable. Typical usage either records commands manually with \doxylink{class_lava_v_k_1_1_command_buffer_a9af1a3b839014a0b42a418cb1be65782}{begin()}/\+\doxylink{class_lava_v_k_1_1_command_buffer_a16541b9c8d52ccde1daffff059b1a224}{begin\+Render\+Pass()}/\+.../\+\doxylink{class_lava_v_k_1_1_command_buffer_abb37dea67982113feb0acc7c26339020}{end()}, or uses the higher-\/level \doxylink{class_lava_v_k_1_1_command_buffer_aa799785d1a4460451b6f04fea6b1483f}{record()} helper that manages that whole lifecycle in one call.
