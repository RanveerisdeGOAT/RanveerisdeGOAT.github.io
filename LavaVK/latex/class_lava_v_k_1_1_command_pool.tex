\doxysubsection{Detailed Description}
Opaque container managing GPU memory pools for command buffer allocation. 

A \doxylink{class_lava_v_k_1_1_command_pool}{Command\+Pool} encapsulates a Vk\+Command\+Pool bound to a specific Queue\+Type. It maintains ownership of all Command\+Buffers allocated from it.
