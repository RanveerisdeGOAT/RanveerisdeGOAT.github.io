\doxysubsection{Detailed Description}
Manages the lifetime of a {\ttfamily Vk\+Surface\+KHR} handle without exposing Vulkan handles directly in its public method signatures. 

Lava\+VK is windowing-\/library agnostic:\+ rather than depending on GLFW, SDL, or a specific platform API to create a {\ttfamily Vk\+Surface\+KHR}, {\ttfamily \doxylink{class_lava_v_k_1_1_surface}{Surface}} takes a {\ttfamily Surface\+Creator} callback supplied by the application, which is invoked once during construction with the owning {\ttfamily Vk\+Instance} and is expected to return a valid {\ttfamily Vk\+Surface\+KHR} (e.\+g. via {\ttfamily glfw\+Create\+Window\+Surface}). The resulting handle is then owned and destroyed by this class via RAII. Copying is disabled; moving transfers ownership.

Example, creating a surface from a GLFW window:\+

\DoxyCodeLine{\ \ \ \ \textcolor{keywordflow}{if}\ (glfwCreateWindowSurface(vkInst,\ window,\ \textcolor{keyword}{nullptr},\ \&rawSurface)\ !=\ VK\_SUCCESS)\ \{}
\DoxyCodeLine{\ \ \ \ \ \ \ \ \textcolor{keywordflow}{return}\ VK\_NULL\_HANDLE;}
