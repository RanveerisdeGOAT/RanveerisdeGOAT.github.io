\doxysubsection{Detailed Description}
Encapsulates a Vulkan shader module ({\ttfamily Vk\+Shader\+Module}). 


\begin{DoxyItemize}
\item Supports loading directly from raw SPIR-\/V binaries ({\ttfamily .spv}), raw SPIR-\/V byte vectors, or dynamically compiling GLSL source files ({\ttfamily .vert}, {\ttfamily .frag}, {\ttfamily .comp}) using embedded Shaderc compiler support. 
\end{DoxyItemize}
