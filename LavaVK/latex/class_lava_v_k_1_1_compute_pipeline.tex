\doxysubsection{Detailed Description}
Abstraction around Vulkan\textquotesingle{}s compute pipeline ({\ttfamily Vk\+Pipeline}). 

Wraps the smaller subset of state needed to create a compute pipeline (a single compute shader stage plus a {\ttfamily \doxylink{class_lava_v_k_1_1_pipeline_layout}{Pipeline\+Layout}}), as opposed to the many rasterization/\+blend/\+depth states required by {\ttfamily \doxylink{class_lava_v_k_1_1_graphics_pipeline}{Graphics\+Pipeline}}. {\ttfamily \doxylink{class_lava_v_k_1_1_compute_pipeline}{Compute\+Pipeline}} is move-\/only RAII:\+ the underlying {\ttfamily Vk\+Pipeline} is created in the constructor and destroyed in the destructor.
