\doxysubsection{Detailed Description}
Abstraction around Vulkan\textquotesingle{}s graphics pipeline ({\ttfamily Vk\+Pipeline}). 

Manages full graphics state setup including shaders, rasterization, multisampling, depth/\+stencil, blending, and dynamic state bindings, all configured through a single \doxylink{struct_lava_v_k_1_1_graphics_pipeline_create_info}{Graphics\+Pipeline\+Create\+Info} rather than the half-\/dozen {\ttfamily Vk\+Graphics\+Pipeline\+Create\+Info} sub-\/structures Vulkan normally requires. {\ttfamily \doxylink{class_lava_v_k_1_1_graphics_pipeline}{Graphics\+Pipeline}} is move-\/only RAII:\+ the underlying {\ttfamily Vk\+Pipeline} is created in the constructor and destroyed in the destructor.
