\doxysubsection{Detailed Description}
Structured, human-\/readable representation of a Vulkan pixel format. 

Raw {\ttfamily Vk\+Format} values are a single flat enum (e.\+g. {\ttfamily VK\+\_\+\+FORMAT\+\_\+\+R8\+G8\+B8\+A8\+\_\+\+SRGB}) that encodes channel order, bit depth, and numeric type all at once, which makes them awkward to construct or inspect programmatically. {\ttfamily \doxylink{class_lava_v_k_1_1_format}{Format}} instead stores those three properties (Channel\+Order, Bit\+Depth, Numeric\+Type) separately and converts to/\+from {\ttfamily Vk\+Format} on demand via \doxylink{class_lava_v_k_1_1_format_ab6f7fb7fbd71c240cfc46a1d6b4aa0aa}{native()} and the implicit {\ttfamily Vk\+Format} conversion operator, so a {\ttfamily \doxylink{class_lava_v_k_1_1_format}{Lava\+VK::\+\+Format}} can be passed anywhere a {\ttfamily Vk\+Format} is expected while still being easy to build and compare.

Example:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{comment}{//\ Build\ a\ format\ instead\ of\ hard-\/coding\ VK\_FORMAT\_R32G32B32\_SFLOAT}}
\DoxyCodeLine{LavaVK::Format\ positionFormat(}
\DoxyCodeLine{\ \ \ \ LavaVK::ChannelOrder::RGB,}
\DoxyCodeLine{\ \ \ \ LavaVK::BitDepth::B32,}
\DoxyCodeLine{\ \ \ \ LavaVK::NumericType::Float);}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ Wrap\ an\ existing\ VkFormat\ and\ inspect\ it}}
\DoxyCodeLine{LavaVK::Format\ surfaceFormat(VK\_FORMAT\_B8G8R8A8\_SRGB);}
\DoxyCodeLine{\textcolor{keywordflow}{if}\ (surfaceFormat.getNumericType()\ ==\ LavaVK::NumericType::Srgb)\ \{\ ...\ \}}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{comment}{//\ Implicitly\ converts\ back\ to\ VkFormat\ when\ needed}}
\DoxyCodeLine{VkFormat\ raw\ =\ positionFormat;}

\end{DoxyCode}
