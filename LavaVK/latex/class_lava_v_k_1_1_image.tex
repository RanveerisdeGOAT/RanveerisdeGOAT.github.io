\doxysubsection{Detailed Description}
Represents a Vulkan image ({\ttfamily Vk\+Image}) together with its backing memory and a default {\ttfamily Vk\+Image\+View}. 

{\ttfamily \doxylink{class_lava_v_k_1_1_image}{Image}} supports two modes of construction:\+ it can allocate and own a brand-\/new {\ttfamily Vk\+Image} and {\ttfamily Vk\+Device\+Memory} from an \doxylink{struct_lava_v_k_1_1_image_create_info}{Image\+Create\+Info}, or it can wrap an externally-\/owned {\ttfamily Vk\+Image} (for example, a swapchain image) without taking ownership of the underlying handle — see \doxylink{class_lava_v_k_1_1_image_ae798fb44e9277eec633f663d9e509979}{owns\+Image()}. In both cases a {\ttfamily Vk\+Image\+View} covering the whole image is created and owned by this object. {\ttfamily \doxylink{class_lava_v_k_1_1_image}{Image}} is move-\/only RAII; the destructor destroys the view, and additionally the image and memory if they are owned.
