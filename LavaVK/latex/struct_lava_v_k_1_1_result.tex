\doxysubsection{Detailed Description}
Lightweight wrapper around {\ttfamily Vk\+Result} with Lava\+VK-\/friendly comparisons and truthiness. 

Many Vulkan calls ({\ttfamily vk\+Acquire\+Next\+Image\+KHR}, {\ttfamily vk\+Queue\+Present\+KHR}, {\ttfamily vk\+Wait\+For\+Fences}, ...) return a {\ttfamily Vk\+Result} that is not simply success/\+failure — values like {\ttfamily VK\+\_\+\+SUBOPTIMAL\+\_\+\+KHR} or {\ttfamily VK\+\_\+\+ERROR\+\_\+\+OUT\+\_\+\+OF\+\_\+\+DATE\+\_\+\+KHR} are meaningful non-\/error conditions the caller must react to. {\ttfamily \doxylink{struct_lava_v_k_1_1_result}{Result}} stores both the raw {\ttfamily Vk\+Result} and a best-\/effort Result\+Code classification, and can be evaluated directly in a boolean context ({\ttfamily true} for \+\#\+Result\+Code::\+\+Success or \+\#\+Result\+Code::\+\+Suboptimal) so common call sites read naturally, while {\ttfamily \doxylink{struct_lava_v_k_1_1_result_a1d8335716f828158c116b6ddc041857d}{value}} and {\ttfamily \doxylink{struct_lava_v_k_1_1_result_a6f80bfbad420d644b42b40753dc8a2ea}{code}} remain available for finer-\/grained handling.

Example:\+
