\doxysubsection{Detailed Description}
Represents a Vulkan buffer ({\ttfamily Vk\+Buffer}) and its backing device memory. 

{\ttfamily \doxylink{class_lava_v_k_1_1_buffer}{Buffer}} owns both the {\ttfamily Vk\+Buffer} handle and the {\ttfamily Vk\+Device\+Memory} allocated to back it, created together in the constructor from a \doxylink{struct_lava_v_k_1_1_buffer_create_info}{Buffer\+Create\+Info} and destroyed together in the destructor. For memory placements that are host-\/visible (\+\#\+Memory\+Usage::\+\+CPU, \+\#\+Memory\+Usage::\+\+CPU\+\_\+\+TO\+\_\+\+GPU, \+\#\+Memory\+Usage::\+\+GPU\+\_\+\+TO\+\_\+\+CPU), the buffer can be written to directly via \doxylink{class_lava_v_k_1_1_buffer_a4c38f9aa95fa71b777cc8993bd29f7da}{map()}/\+\doxylink{class_lava_v_k_1_1_buffer_a9240a18aadb722251e4653a5e25b4ddb}{unmap()} or the \doxylink{class_lava_v_k_1_1_buffer_a92e71f79f87085f93c0aba83676243e4}{upload()} convenience overloads, which map, {\ttfamily memcpy}, and unmap in one call. {\ttfamily \doxylink{class_lava_v_k_1_1_buffer}{Buffer}} is move-\/only RAII; copying is disabled.

Example:\+

\DoxyCodeLine{\});}
\DoxyCodeLine{vertexBuffer.upload(vertices);}
