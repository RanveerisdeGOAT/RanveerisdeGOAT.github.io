\doxysubsection{Detailed Description}
CPU-\/\+GPU synchronization primitive. 

A \doxylink{class_lava_v_k_1_1_fence}{Fence} is used by the CPU to determine when GPU work has completed. Unlike semaphores, fences can be waited on and reset directly by the CPU. A common use is to gate CPU access to a resource (such as re-\/recording a per-\/frame command buffer) until the GPU has finished consuming it. {\ttfamily \doxylink{class_lava_v_k_1_1_fence}{Fence}} is move-\/only RAII:\+ the underlying {\ttfamily Vk\+Fence} is created in the constructor and destroyed in the destructor.

Example, the classic "{}wait for the previous frame, then reset"{} pattern:\+

\DoxyCodeLine{\textcolor{comment}{*}}
\DoxyCodeLine{\textcolor{comment}{*\ //\ Each\ frame:}}
\DoxyCodeLine{\textcolor{comment}{*\ inFlightFence.wait();}}
\DoxyCodeLine{\textcolor{comment}{*\ inFlightFence.reset();}}
\DoxyCodeLine{\textcolor{comment}{*\ //\ ...\ record\ and\ submit\ commands,\ signaling\ inFlightFence\ on\ completion\ ...}}
