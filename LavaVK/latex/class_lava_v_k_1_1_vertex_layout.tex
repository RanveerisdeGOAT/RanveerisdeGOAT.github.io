\doxysubsection{Detailed Description}
Builder describing a vertex buffer\textquotesingle{}s binding and per-\/attribute layout for a pipeline. 

{\ttfamily \doxylink{class_lava_v_k_1_1_vertex_layout}{Vertex\+Layout}} produces the {\ttfamily Vk\+Vertex\+Input\+Binding\+Description} and {\ttfamily Vk\+Vertex\+Input\+Attribute\+Description} list a {\ttfamily \doxylink{class_lava_v_k_1_1_graphics_pipeline}{Graphics\+Pipeline}} needs to interpret vertex buffer data, without the caller manually computing strides or {\ttfamily offsetof}-\/style byte offsets. \doxylink{class_lava_v_k_1_1_vertex_layout_a3a051452c47b81ea49e28791b42b93c7}{create()} establishes the binding (stride taken from {\ttfamily sizeof(\+Vertex)}), and chained calls to \doxylink{class_lava_v_k_1_1_vertex_layout_a23f6cc315daacbff95341c303e984cae}{attribute()} add one attribute per struct member, using a pointer-\/to-\/member template argument so the byte offset is computed automatically via \doxylink{struct_lava_v_k_1_1_member_traits}{Member\+Traits}.
