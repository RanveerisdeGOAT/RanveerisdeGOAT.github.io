\doxysubsection{Detailed Description}
Encapsulates a Vulkan {\ttfamily Vk\+Pipeline\+Layout}. 

Defines descriptor set layouts and push constants used across pipeline stages. A {\ttfamily \doxylink{class_lava_v_k_1_1_pipeline_layout}{Pipeline\+Layout}} is required to construct both a {\ttfamily \doxylink{class_lava_v_k_1_1_graphics_pipeline}{Graphics\+Pipeline}} and to record {\ttfamily push\+Constants}/\+descriptor-\/binding commands against a command buffer, since it declares which resources and push constant ranges shaders may access. {\ttfamily \doxylink{class_lava_v_k_1_1_pipeline_layout}{Pipeline\+Layout}} is non-\/copyable RAII:\+ the underlying {\ttfamily Vk\+Pipeline\+Layout} is created in the constructor and destroyed in the destructor.
