Detailed Description

Wrapper for Vulkan VkRenderPass.

Configures attachments (color, depth/stencil), subpasses, and dependencies. Most applications only need a single color (+ optional depth) attachment render pass, provided by the convenience constructor; applications with more complex attachment layouts (multiple subpasses, input attachments, MSAA resolve targets, ...) can instead supply a raw VkRenderPassCreateInfo directly. RenderPass is non-copyable RAII: the underlying VkRenderPass is created in the constructor and destroyed in the destructor.

Example:

LavaVK::RenderPass renderPass(
device,
LavaVK::Format(LavaVK::ChannelOrder::BGRA, LavaVK::BitDepth::B8, LavaVK::NumericType::Srgb),
LavaVK::Format(LavaVK::ChannelOrder::D, LavaVK::BitDepth::B32, LavaVK::NumericType::Float)
);
