Detailed Description

Abstraction around Vulkan's compute pipeline (VkPipeline).

Wraps the smaller subset of state needed to create a compute pipeline (a single compute shader stage plus a PipelineLayout), as opposed to the many rasterization/blend/depth states required by GraphicsPipeline. ComputePipeline is move-only RAII: the underlying VkPipeline is created in the constructor and destroyed in the destructor.

Example:

LavaVK::ComputePipeline pipeline(device, {
.computeShader = &computeShader,
.layout = &pipelineLayout,
});
cmd.bindPipeline(pipeline);
cmd.dispatch(groupCountX, groupCountY, groupCountZ);
