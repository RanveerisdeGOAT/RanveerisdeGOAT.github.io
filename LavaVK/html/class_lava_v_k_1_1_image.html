Detailed Description

Represents a Vulkan image (VkImage) together with its backing memory and a default VkImageView.

Image supports two modes of construction: it can allocate and own a brand-new VkImage and VkDeviceMemory from an ImageCreateInfo, or it can wrap an externally-owned VkImage (for example, a swapchain image) without taking ownership of the underlying handle — see ownsImage(). In both cases a VkImageView covering the whole image is created and owned by this object. Image is move-only RAII; the destructor destroys the view, and additionally the image and memory if they are owned.
