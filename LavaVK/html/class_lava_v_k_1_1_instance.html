Detailed Description

Encapsulates a Vulkan instance (VkInstance) handle, managing its creation, lifetime, and cleanup.

Instance is the entry point of any LavaVK application and the first object created before anything else (surfaces, GPU selection, devices, etc.), since those all require a valid VkInstance to be queried or constructed. It owns the underlying VkInstance handle, creating it in the constructor from an InstanceCreateInfo and destroying it in the destructor. In debug builds, validation layers are enabled automatically unless disabled via InstanceCreateInfo::enableValidation.

This class implements RAII semantics and move operations. Copying is explicitly disabled to prevent multiple deletions of the underlying handle.

Example usage, requesting the extensions GLFW needs to present to a window:

uint32_t extensionCount = 0;
const char **glfwExtensions = glfwGetRequiredInstanceExtensions(&extensionCount);
LavaVK::Instance instance({
.applicationName = "My Application",
.extensions = std::vector<const char *>(glfwExtensions, glfwExtensions + extensionCount)
});
