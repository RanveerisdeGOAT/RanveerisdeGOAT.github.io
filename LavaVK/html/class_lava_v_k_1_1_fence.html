Detailed Description

CPU-GPU synchronization primitive.

A Fence is used by the CPU to determine when GPU work has completed. Unlike semaphores, fences can be waited on and reset directly by the CPU. A common use is to gate CPU access to a resource (such as re-recording a per-frame command buffer) until the GPU has finished consuming it. Fence is move-only RAII: the underlying VkFence is created in the constructor and destroyed in the destructor.

Example, the classic "wait for the previous frame, then reset" pattern:

LavaVK::Fence inFlightFence(device, /*signaled=*\/true);
*
* // Each frame:
* inFlightFence.wait();
* inFlightFence.reset();
* // ... record and submit commands, signaling inFlightFence on completion ...
*
