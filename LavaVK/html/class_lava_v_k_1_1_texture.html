Detailed Description

Represents a GPU texture: an Image paired with a VkSampler.

Texture combines the two resources most shader sampling operations need together: an Image (with its view) and a VkSampler describing how that image is filtered and addressed. It supports two creation paths: allocating an empty GPU-only image (e.g. a storage image or render target) from a TextureCreateInfo, or loading image data from disk and uploading it to a new sampled image. Texture is move-only RAII: the sampler is created in the constructor and destroyed, along with the owned Image, in the destructor.

Example, loading a texture from disk:

LavaVK::Texture texture(device, "assets/textures/brick.png");
