Detailed Description

Lightweight, queryable handle to a physical Vulkan GPU (VkPhysicalDevice).

GPUHardware does not own or create any Vulkan resources — it simply wraps a VkPhysicalDevice (enumerated from an Instance) along with its cached VkPhysicalDeviceProperties, and exposes convenience queries used when choosing which GPU to render on and which queue families to request from it. A GPUHardware is passed to the Device constructor to create the logical device.

Example, letting LavaVK pick the best available GPU automatically:

const LavaVK::GPUHardware &gpu = LavaVK::GPUHardware::selectOptimalGPU(instance, surface);
LavaVK::Device device(gpu, { LavaVK::QueueType::GRAPHICS, LavaVK::QueueType::PRESENT }, &surface);

uint32_t LavaVK::GPUHardware::findQueueFamily ( QueueType type,
const Surface * surface ) const
nodiscard

Finds a queue family supporting the requested operations.

For QueueType::PRESENT, this delegates to findPresentQueueFamily(). For all other queue types, it searches the device's reported queue families for one whose flags include the corresponding Vulkan queue bit.

Parameters
typeThe kind of queue operations required (graphics, compute, transfer, present, ...).
surfaceSurface to test presentation support against; required (non-null) when type is QueueType::PRESENT, otherwise ignored.
Returns
Index of a queue family satisfying type.
Exceptions
std::runtime_errorIf no queue family supports the requested operations.
