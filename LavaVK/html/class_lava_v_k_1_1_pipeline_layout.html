Detailed Description

Encapsulates a Vulkan VkPipelineLayout.

Defines descriptor set layouts and push constants used across pipeline stages. A PipelineLayout is required to construct both a GraphicsPipeline and to record pushConstants/descriptor-binding commands against a command buffer, since it declares which resources and push constant ranges shaders may access. PipelineLayout is non-copyable RAII: the underlying VkPipelineLayout is created in the constructor and destroyed in the destructor.

Example:

LavaVK::PushConstantRange mvpRange{
.stageFlags = LavaVK::STAGE_VERTEX_BIT,
.offset = 0,
.size = sizeof(glm::mat4)
};
LavaVK::PipelineLayout pipelineLayout(device, {}, { mvpRange });
