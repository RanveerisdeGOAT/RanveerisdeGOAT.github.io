Detailed Description

Wrapper around VkCommandBuffer for recording GPU rendering and compute instructions.

Command buffers are allocated from a CommandPool and submitted to a GPU queue for execution. Members are marked const as recording commands modifies the GPU recording state pointed to by the handle, rather than the C++ handle itself.
